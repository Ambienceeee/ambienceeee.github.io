Ambience Client

A desktop launcher for Minecraft: Java Edition, for Windows, macOS and Linux.

Ambience Client installs official Minecraft versions, keeps each setup in its own folder, and starts the game with your own Microsoft account. It's a small independent project. It is still in development and is only being tested privately. There is no public download yet.

What it does

  • Lists every release, snapshot and old beta/alpha from Mojang's official version manifest, and downloads the game files from Mojang's servers. Each file is checked against its SHA-1 hash.
  • Keeps instances separate. Each one has its own game folder, saves, mods, memory setting and Java choice.
  • Supports Fabric and Quilt, and can search Modrinth and install a mod into a chosen instance.
  • Has an optional in-game HUD (keystrokes, FPS, CPS, armor) for Fabric. The layout is saved on your computer.
  • Finds installed Java runtimes and picks one that matches the version.

Signing in

To play online you sign in with the Microsoft account that owns Minecraft. The launcher uses Microsoft's device code flow, so you type your password only on Microsoft's own website, never in the launcher.

  1. The launcher asks Microsoft for a sign-in code and shows it to you.
  2. You open microsoft.com/link in your browser, enter the code and sign in there.
  3. The launcher receives a Microsoft token with the scopes XboxLive.signin and offline_access, and nothing else.
  4. It exchanges that token with Xbox Live (user token, then XSTS) and then with Minecraft services, which return a Minecraft access token.
  5. It checks that the account owns Minecraft: Java Edition and reads your Minecraft profile (username and UUID).
  6. When you press Launch, the Minecraft token is passed to the game on your computer, which is how the official launcher starts it too.

It's a public client: there is no client secret, and no server of ours sits in the middle. Every request goes directly from your computer to Microsoft, Xbox Live or Mojang.

The launcher has no analytics or telemetry, and there is no Ambience account or server. Nothing above is ever sent to us. The full details are in the privacy policy.

What it won't do

  • It won't let anyone play without owning the game. Online play needs a Microsoft account that owns Minecraft: Java Edition.
  • It won't bypass or change Mojang's authentication, or help anyone join online-mode servers without a valid account.
  • It won't ask for, see or store your password.
  • It won't share, sell or upload account data.

There is an offline mode for singleplayer and LAN, like other launchers. It uses a local name only, and servers that verify accounts will still refuse it.

Status

  • Development build, private testing only.
  • Built with Tauri 2 and Rust, with a React interface. It's a native desktop app, not a website.
  • Platforms: Windows 10 and 11, macOS 12 or newer, and Linux.
